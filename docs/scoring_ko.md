# 채점

각 트라이얼은 최대 100점의 계층형 채점 시스템을 사용합니다.
예선 단계는 3번의 트라이얼이 있으므로 제출물의 최대 점수는 300점입니다.

## 채점 티어 개요

| 티어 | 이름 | 설명 |
|------|------|-------------|
| Tier 1 | 모델 유효성 | 모델이 로드되고 기대에 부합하는지 사전 조건 검사 |
| Tier 2 | 성능 및 수렴 | 모션 품질에 대한 정량적 지표 |
| Tier 3 | 케이블 삽입 | 주요 목표 - 성공 또는 부분 삽입 검증 |

## Tier 1: 모델 유효성 (사전 조건)

제출물이 오류 없이 로드되고 실행되는지 확인하는 검사입니다.

- 모델은 제출된 정책을 성공적으로 활성화하고 `InsertCable` 액션 요청에 응답할 수 있어야 합니다. 제출된 정책은 `MotionUpdate`(목표 위치/속도) 또는 `JointMotionUpdate`(목표 관절 상태)를 통해 로봇 팔 컨트롤러에 유효한 명령을 전송해야 합니다.
- 정책은 [대회 규칙](./challenge_rules_ko.md#aic_model)에 정의된 모든 행동 요구사항을 준수해야 합니다.
- 이 검사에 실패한 제출물은 채점되지 않습니다.

| 결과 | 점수 |
|---------|-------|
| 검증 통과 | 1 |
| 검증 실패 | 0 |

## Tier 2: 성능 및 수렴

태스크 실행 중 로봇 모션 품질을 측정하는 정량적 지표입니다.

### 궤적 부드러움 (0~6점)

엔드 이펙터 궤적의 부드러움을 측정합니다. 낮은 저크 값은 더 부드럽고 제어된 모션을 나타냅니다. 저크는 팔이 움직일 때만 누적되므로(속도 > 0.01 m/s) 정지 기간은 평균을 희석하지 않습니다. 태스크가 성공적으로 완료되거나 플러그의 최종 위치가 목표 포트 근처(Tier 3 점수 > 0)인 경우에만 부여됩니다.

- **지표**: 선형 저크 크기의 시간 가중 평균 (m/s³), Savitzky–Golay 필터(15-샘플 윈도우에 대한 로컬 이차 다항식 적합)로 계산
- **채점**: 저크에 반비례
  - 저크 = 0 m/s³ → 6점 (최대)
  - 저크 ≥ 50 m/s³ → 0점 (최소)
  - 임계값 사이는 선형 보간
- **미부여**: 플러그의 최종 위치가 목표 포트의 최대 허용 거리를 벗어나는 경우(Tier 3 점수 ≤ 0) 0점.

### 태스크 소요 시간 (0~12점)

빠른 태스크 완료에 보상을 줍니다. 태스크가 성공적으로 완료되거나 플러그의 최종 위치가 목표 포트 근처(Tier 3 점수 > 0)인 경우에만 부여됩니다.

- **지표**: 태스크 시작부터 종료까지 경과 시간
- **채점**: 소요 시간에 반비례
  - 소요 시간 ≤ 5초 → 12점 (최대)
  - 소요 시간 ≥ 60초 → 0점 (최소)
  - 임계값 사이는 선형 보간
- **미부여**: 플러그의 최종 위치가 목표 포트의 최대 허용 거리를 벗어나는 경우(Tier 3 점수 ≤ 0) 0점.

### 궤적 효율성 (0~6점)

태스크 실행 중 엔드 이펙터가 이동한 총 거리를 측정합니다. 더 짧고 직접적인 경로가 높은 점수를 받습니다. 태스크가 성공적으로 완료되거나 플러그의 최종 위치가 목표 포트 근처(Tier 3 점수 > 0)인 경우에만 부여됩니다.

- **지표**: 엔드 이펙터 위치의 누적 유클리드 거리 (미터)
- **채점**: 총 경로 길이에 반비례
  - 경로 길이 ≤ 초기 플러그-포트 거리 → 6점 (최대)
  - 경로 길이 ≥ 1m + 초기 플러그-포트 거리 → 0점 (최소)
  - 임계값 사이는 선형 보간
- 최소 경로 길이(만점 기준)는 트라이얼 시작 시 플러그와 포트 사이의 초기 유클리드 거리로 동적으로 설정됩니다.
- **미부여**: 플러그의 최종 위치가 목표 포트의 최대 허용 거리를 벗어나는 경우(Tier 3 점수 ≤ 0) 0점.

### 삽입 힘 패널티 (0 ~ -12점)

삽입 과정에서 과도한 힘에 패널티를 부여하여 부드러운 조작을 장려합니다.
힘 센서 측정값은 시작 시 영점 조정되므로 기준값이 0 N에 가깝습니다.

- **힘 임계값**: 20 N
- **지속 시간 임계값**: 1초
- **패널티**: 임계값을 초과하는 힘이 지속 시간 임계값보다 오래 지속되면 -12점
- **패널티 없음**: 과도한 힘이 감지되지 않거나 지속 시간 임계값 내에 있는 경우

### 접촉 금지 구역 패널티 (0 ~ -24점)

제한된 환경 영역(인클로저 또는 태스크 보드)과의 충돌에 패널티를 부여합니다.

- **패널티**: 접촉 금지 개체와 접촉이 감지되면 -24점
- **패널티 없음**: 금지된 접촉이 발생하지 않는 경우

## Tier 3: 태스크 성공

성공적인 케이블 삽입을 검증하는 주요 목표입니다. 채점은 완전한 삽입과 포트를 향한 부분적 진전 모두에 보상하는 두 단계 접근법을 사용합니다.

### 성공적인 삽입 (-12 ~ 75점)

케이블 커넥터가 **올바른** 목표 포트에 완전히 삽입된 경우, 접촉 센서로 검증:

| 결과 | 점수 |
|---------|-------|
| 올바른 포트 삽입 | 75 |
| 잘못된 포트 삽입 | -12 |

### 부분 삽입 및 근접도 (0~50점)

완전한 삽입이 감지되지 않으면, 태스크 완료 시 플러그가 포트에 얼마나 가까운지에 따라 점수가 매겨집니다:

- **부분 삽입** (38~50점): 플러그가 포트 입구와 포트 바닥 사이의 경계 상자 내에 있는 경우(5mm x-y 허용 오차 내), 삽입 깊이에 비례하여 점수가 부여됩니다. 더 깊이 삽입될수록 높은 점수.
- **근접도** (0~25점): 플러그가 포트 내부에 없는 경우, 포트로부터의 최대 허용 거리에 반비례하여 점수가 부여됩니다. 최대 거리는 플러그와 포트 사이의 초기 거리의 절반으로 설정됩니다.
  - 포트 입구에서 → 25점 (최대)
  - 최대 거리 밖 → 0점 (최소)
  - 임계값 사이는 선형 보간

## 총점 계산

```
총점 = Tier 1 + Tier 2 + Tier 3
```

여기서:
- **Tier 1**: 0 또는 1점
- **Tier 2**: 부드러움(0~6), 소요 시간(0~12), 효율성(0~6), 패널티(힘: 0 ~ -12, 접촉: 0 ~ -24)의 합
- **Tier 3**: 삽입 성공(최대 75), 또는 부분 삽입/근접도 점수(최대 50)
- **트라이얼당 최대 점수**: 100점 (1 + 6 + 12 + 6 + 75)

## 최종 순위

최종 순위는 모든 트라이얼에 걸쳐 점수를 누적하여 결정하며, Tier 2의 정량적 성과 지표와 Tier 3의 태스크 성공 점수를 결합합니다.
