# 경연 단계

## 예선 단계: 모델 훈련하기

예선 단계에서 참가자들은 오픈소스 소프트웨어와 시뮬레이터를 포함한 선호하는 도구를, Intrinsic 대회 툴킷과 함께 사용하여 케이블 삽입 태스크를 위한 모델을 훈련시킵니다. 제출된 모든 모델은 Gazebo를 사용하여 평가됩니다.

![](../../media/qualification_overview.png)

### 기술 개요

이 단계의 핵심 기술 요구사항(설정 제약, 트라이얼 설명, 평가 지표 포함)은 [예선 단계: 기술 개요](./qualification_phase_ko.md) 문서를 참조하세요.

### 구현 워크플로우

예선을 통과하려면 참가자들은 [대회 규칙](./challenge_rules_ko.md)에 명시된 행동 요구사항을 준수하는 ROS 2 노드를 만들어야 합니다.

#### 권장 접근법: `aic_model` 프레임워크 사용

편의를 위해 모든 ROS 2 라이프사이클 관리와 보일러플레이트를 처리하는 `aic_model` 프레임워크를 제공합니다. Python 정책 클래스만 구현하면 됩니다:

1. **정책 클래스 만들기:** [`Policy`](https://github.com/intrinsic-dev/aic/blob/main/aic_model/aic_model/policy.py)에서 파생되는 Python 클래스를 정의합니다.
2. **`insert_cable()` 구현:** `aic_engine`이 새 태스크를 요청할 때 이 메서드가 호출됩니다. 관측 데이터와 로봇 제어를 위한 콜러블 메서드를 수신합니다.
3. **모델 로드:** 클래스가 인스턴스화될 때 훈련된 정책(예: PyTorch 체크포인트, ONNX 모델, 또는 제어 알고리즘)을 초기화합니다.
4. **관측 처리:** 제공된 `get_observation()` 콜백을 사용하여 최대 20Hz로 센서 데이터를 가져옵니다.
5. **명령 출력:** `move_robot()` 및 기타 제공된 메서드를 사용하여 로봇에 명령을 내립니다.
6. **완료 시 반환:** 태스크가 완료되면 `insert_cable()` 메서드가 반환해야 합니다.

> **튜토리얼:** 단계별 가이드는 [새 정책 노드 만들기](./policy_ko.md#튜토리얼-새-정책-노드-만들기)를 참조하세요.
>
> **예제:** 참조 구현: [`WaveArm.py`](../aic_example_policies/aic_example_policies/ros/WaveArm.py)

#### 대안: 직접 노드 구현

다음 조건을 충족한다면 처음부터 직접 ROS 2 노드를 구현할 수도 있습니다:
- 이름이 `aic_model`이고 ROS 2 Lifecycle 인터페이스를 구현
- `/insert_cable` 액션 서버에 응답
- [대회 규칙](./challenge_rules_ko.md)의 모든 요구사항 준수

### 참가 가이드라인

* **정책 개발:** 참가자들은 다음을 포함한 어떤 접근 방식이든 자유롭게 사용할 수 있습니다:
    * 실제 원격 조작 데이터.
    * 선택한 시뮬레이터(MuJoCo, Isaac Sim, O3DE 등)에서의 훈련.
    * 고전적인 제어 알고리즘.
* **인터페이스 요구사항:** 정책(위에서 설명한 서비스로 래핑된)은 표준 형식을 사용하여 세계 정보를 소비하고 액션을 출력해야 합니다.
* **평가:** 제공된 평가 시뮬레이터(Gazebo)가 참가자 모델의 성과를 채점합니다.
    * 개발 중에 참가자들은 평가 시뮬레이터를 로컬에서 실행하여 성과를 테스트할 수 있습니다.
    * 제출 시 클라우드 인스턴스가 동일한 평가 시뮬레이터를 실행하여 공식 점수를 기록합니다.

## Phase 1: Flowstate에서 개발하기

Phase 1에 진출하는 팀들은 **Intrinsic Flowstate**(개발 환경)와 **Intrinsic Vision Model**에 접근권을 얻습니다. 이 도구들을 사용하여 팀들은 훈련된 모델을 통합한 완전한 로봇 케이블 처리 솔루션을 구축합니다.

*준비 중*

## Phase 2: 실제 로봇으로 실행하기

Phase 2 참가자들은 Intrinsic 본사의 실물 로봇 작업 셀에 솔루션을 배포합니다. 이 단계는 실제 환경에서 솔루션을 검증하고 상금 수상자를 결정합니다.

*준비 중*
